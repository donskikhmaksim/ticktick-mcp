## Два правила, которые легко нарушить по невнимательности

**Пуша нет.** Пока идёт разбор задачника, ни одна ветка не уходит в удалённый
репозиторий: Railway пересобирает и перезапускает боевой сервер при пуше, а
через этот сервер прямо сейчас идут сотни операций. Перезапуск посреди
исполнения оставит часть операций в неизвестном состоянии. Подробно и с
причинами — часть 2.

**Следствие, которое легко упустить:** раз пушей нет, сборка на стороне
GitHub не запускается. Тесты гоняются локально, полным набором, с настоящим
Postgres (`TICKTICK_TEST_PG_DSN`) — без него тесты долговечных планов молча
пропускаются, и «зелёный» прогон окажется неполным.
