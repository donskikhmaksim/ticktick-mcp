## Сквозной пункт §7.4 (язык вывода) — по всем пяти методам

⚠️ **Расхождение у всех пяти.** Весь видимый Максиму текст — на английском:
«Found N projects», «No tasks found», «Title:», «Priority:», «Status:», «Error
fetching project: ...» и т.д. (server.py:899, 949, 368-397, 894/923/945/976).
Формально §7 озаглавлен «относится к write-методам (и к отказам тоже)», но
формулировка §7.4 первым пунктом — «Весь текст, видимый Максиму (ответы
инструментов...) — по-русски. Без исключений» — не содержит явной оговорки
«только write». Т.к. это был явный пункт ревизии в задаче, фиксирую как
расхождение, требующее решения Максима: либо явно ограничить §7.4 только
write-методами (тогда read — не баг), либо перевести человеко-читаемые куски
(`format_task`, `format_project`, error-сообщения) на русский.
